## How it works

`main.ts` (Node 22, built-ins only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`, byte for byte, every run. The image itself was generated for this entry with a Python/PIL script in the build session (`gen.py`, kept in this repository) and is held in this repository.
